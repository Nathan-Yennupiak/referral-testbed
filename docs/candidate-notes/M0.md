# M0 Foundations: notes for the candidate

## What was built

The empty shell that every later milestone sits in. There is no research logic yet.

- **A monorepo.** One repository with one package per component (`packages/common` today, more in later milestones), managed with pnpm workspaces. Packages can depend on each other, so A0, A1 and A2 will all import the _same_ validation code from `common` rather than three copies of it.
- **Strict TypeScript.** The compiler rejects implicit `any`, unchecked array access and similar mistakes. Every package shares `tsconfig.base.json`.
- **Tests.** Vitest runs unit tests; fast-check (property-based testing) is installed and comes into use in M1.
- **CI.** `.github/workflows/ci.yml` runs a format check, type check, build and tests on every push. It will run on GitHub once the repository has a remote; until then the same commands run locally with `pnpm run ci`.
- **Documents.** `SPEC.md` and `docs/THREAT-MODEL.md` are verbatim copies of your two documents. `docs/DECISIONS.md` records the decisions taken so far (D-001 to D-018).

## Why it was designed this way

- **Pinned exact versions** (`pnpm-lock.yaml`, `VERSIONS.md`, and CI actions pinned by commit SHA) mean a result produced today can be reproduced later with the same software. Every run will record the hash of `VERSIONS.md`.
- **LF line endings everywhere.** You work on Windows and CI runs on Linux. If line endings differed, M1's "same seed gives a byte-identical file" test would fail for reasons unrelated to the research.

## Known limitations

- CI has not yet run on GitHub; it will once the private remote is added (D-007).
- There is no linter, only the strict compiler (D-003).

## Likely examiner questions

- _How do you know which software environment produced your results?_ Every dependency is pinned exactly; `VERSIONS.md` lists them, and every run manifest will record its hash and the git commit.
- _Why TypeScript for everything, including the blockchain chaincode?_ One language means the lifecycle validation used by A0, A1 and A2 is literally the same code, which removes a source of unfairness between the architectures.
